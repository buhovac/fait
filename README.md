# Fait

Petite liste de tâches du jour : ajouter, cocher, supprimer, filtrer.
Les tâches restent dans le navigateur (localStorage) ; rien n'est envoyé sur le réseau.

```sh
npm install
npm run dev      # lance l'application en local (ajouter `-- --host` pour l'ouvrir depuis un téléphone sur le même Wi-Fi)
npm test         # lance les tests
npm run build    # vérifie les types et construit la version finale dans dist/
```
